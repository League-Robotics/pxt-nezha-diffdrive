# VOID — run interrupted by a physical obstruction

The 2026-09-06 tovez square tour recorded here was invalidated by a cat
on the playfield table (stakeholder, at the time of the run). The robot
was physically displaced mid-tour.

The signature is exactly what an external shove looks like, and it is
kept here as a worked example: the robot's OWN odometry reported a
167.0 mm closure while the overhead camera measured 406.5 mm and
-49.50 deg of net heading over the same run. Odometry integrates
encoder deltas and cannot see a displacement its wheels did not
produce; only the external instrument caught it.

Do NOT cite any number in this directory as a measurement of the
firmware. The replacement run is its sibling in the parent directory.
